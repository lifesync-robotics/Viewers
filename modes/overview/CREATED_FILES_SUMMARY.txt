WHAT THIS MODE DOES:
================================================================================

The Overview Mode displays a medical imaging series in a 4×4 grid showing
16 evenly-spaced frames across the entire series. This provides:

• Quick visual overview of full scan range
• Identification of key anatomical regions
• Initial case triage and review
• Quality assurance checks

Frame Distribution Example:
- For 150-frame series: Shows frames 0, 10, 20, 30... 150
- For 50-frame series: Shows frames 0, 3, 7, 10... 50
- Algorithm: frame[i] = totalFrames × (i / 15)

COMPARISON TO OTHER MODES:
================================================================================

Standard OHIF Longitudinal:
- Layout: Single viewport
- Panels: Thumbnails + Measurements
- Use: Detailed frame-by-frame review

LifeSync Longitudinal (Your Custom):
- Layout: Single viewport
- Panels: Thumbnails + 5 surgical panels
- Use: Surgical planning

Overview Mode (NEW):
- Layout: 4×4 grid (16 viewports)
- Panels: Thumbnails + Measurements
- Use: Quick series overview

================================================================================
INSTALLATION STEPS:
================================================================================

1. Build the mode:
   cd Viewers/modes/overview
   yarn install
   yarn build

2. Register with OHIF:
   cd ../../platform/app
   yarn run cli add-mode @ohif/mode-overview

3. Verify installation:
   yarn run cli list-modes

4. Start development server:
   yarn dev

5. Access the mode:
   http://localhost:3000/overview?StudyInstanceUIDs=...

CUSTOMIZATION OPTIONS:
================================================================================

Change Grid Size:
  Edit src/hangingProtocol.ts
  Modify: rows & columns in viewportStructure
  Update: viewports array length

Add Custom Panels:
  Edit src/index.ts
  Add to: rightPanels array

Modify Frame Distribution:
  Edit src/hangingProtocol.ts
  Change: position calculation algorithm

================================================================================
TROUBLESHOOTING:
================================================================================

Issue: Mode not appearing
Solution: Run `yarn run cli add-mode @ohif/mode-overview`

Issue: Grid not displaying
Solution: Check browser console for hanging protocol errors

Issue: Performance slow
Solution: Check GPU acceleration is enabled

Issue: Frames not evenly spaced
Solution: Verify series has sufficient frames (ideally 16+)
