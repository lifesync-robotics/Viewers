BUG #1 FIXED: 4×4 Grid Not Activating
================================================================================

STATUS: ✅ FIXED

PROBLEM:
- Overview mode was not displaying 4×4 grid on mode enter
- Only single viewport was shown

ROOT CAUSE:
- Missing onModeEnter lifecycle hook
- Hanging protocol was not being registered
- No custom image load strategy for frame distribution

SOLUTION:
1. Added onModeEnter() hook to register hanging protocol
2. Created custom image load strategy for evenly-spaced frames
3. Added customViewportProps to store grid position
4. Protocol now automatically applies 4×4 grid

WHAT WAS CHANGED:
✅ src/index.ts       - Added lifecycle hooks + image load strategy
✅ src/hangingProtocol.ts  - Added imageLoadStrategy reference
